### Title
Reflection principles and bounds for class group torsion

### Authors
Jordan S. Ellenberg and Akshay Venkatesh

### Journal
International Mathematics Research Notices 2007, Art. ID rnm002

### Main Technique: Reflection Principle for Class Group Torsion

The paper uses "reflection" in the sense of the Scholz reflection theorem and its generalizations. The core strategy:

1. **Setup**: For a number field K and prime l, study Cl(K)[l] = l-torsion subgroup of the class group.

2. **Split prime injection**: For a prime p that splits completely in K and satisfies p ≡ 1 (mod l), there is an injection:
   Cl(K)[l] ↪ (O_K/p)^× [l-torsion]

3. **Bound**: Since p splits, O_K/p ≅ F_p^[K:Q], so the l-torsion has size at most p^[K:Q].

4. **Upper bound**: Taking the product over many split primes: |Cl(K)[l]| ≤ p^[K:Q] for each such p.

5. **Lower bound (reflection)**: The "reflection" direction goes the other way — using the structure of norm-1 elements to bound the class group from below using similar split prime information.

### Application in Unit Distance Proof (arXiv:2605.20695, Lemma 2.2)

The Ellenberg-Venkatesh technique is adapted as follows:

Let K be a CM field with K = K̄ (closed under complex conjugation). Let P₁,...,Pₛ be distinct prime ideals with Pᵢ ≠ P̄ⱼ for all i,j. Let kⱼ be positive integers and Q = ∏(Pⱼ P̄ⱼ)^(kⱼ).

Define U = {u ∈ Q^(-2) : |u| = 1} (norm-1 elements with controlled denominators).

Then: |U| ≥ ∏(kⱼ + 1) / h(K)

where h(K) is the class number. This uses the pigeonhole principle: there are ∏(kⱼ + 1) ideals of the form ∏Pⱼ^(aⱼ) P̄ⱼ^(bⱼ) with 0 ≤ aⱼ, bⱼ ≤ kⱼ and aⱼ + bⱼ = kⱼ (using the CM condition). Two ideals in the same ideal class differ by a principal ideal generated by a norm-1 unit. By pigeonhole, at least ∏(kⱼ+1)/h(K) such ideals are in the same class, giving that many norm-1 units.

### Key Lemma Structure (from references)

**Lemma** (Ellenberg-Venkatesh style): For a CM field K of degree 2f over Q, with h = h(K) the class number, and split primes p₁,...,pₛ each splitting as PᵢP̄ᵢ in K, the number of elements of norm 1 in O_K with controlled p-adic valuations satisfies a lower bound of order (∏ kⱼ) / h.

**Bound on h**: For CM fields with bounded root discriminant, class numbers can be bounded using the Minkowski bound: h(K) ≤ M(K) = (4/π)^(r₂) * (n!/n^n) * √|disc(K)|.
