# Mathlib Documentation: CM Fields

This documentation covers the `NumberField.IsCMField` module in Mathlib, which provides comprehensive formalization of CM (Complex Multiplication) fields in algebraic number theory.

## Core Definition

A **CM field** is formalized as a field `K` that is:
- "totally complex" (has no real embeddings into ℂ)
- a "quadratic extension of its maximal real subfield K⁺"

This matches the classical definition where a CM-field represents a totally complex quadratic extension of a totally real field.

## Key Structures and Results

**Complex Conjugation**: The module defines `complexConj`, a canonical automorphism of order 2 that "acts as complex conjugation on embeddings into ℂ" and generates the Galois group of K/K⁺.

**Real Units**: The subgroup `realUnits` consists of units in the ring of integers of K that are "fixed by complex conjugation," which correspond precisely to units from the maximal real subfield.

**Index Invariant**: The `indexRealUnits` measures the index of the subgroup generated by real units and roots of unity, which "equals either 1 or 2" with explicit characterization provided.

**Regulator Relationship**: A notable result states that the ratio of regulators satisfies: "regulator K / regulator K⁺ = 2^rank * (indexRealUnits K)⁻¹"

## Constructors and Instances

The module provides multiple ways to establish CM structure:
- Direct CM-extensions via `ofCMExtension`
- Abelian Galois extensions of ℚ via `of_isAbelianGalois`
- Cyclotomic extensions via `IsCyclotomicExtension.Rat.isCMField`

## Key Lean API

- `IsCMField.complexConj` — the complex conjugation automorphism
- `IsCMField.complexEmbedding_complexConj` — behavior of complexConj on complex embeddings
- `IsCyclotomicExtension.Rat.isCMField` — cyclotomic extensions ℚ(ζ_n) with n > 2 are CM

## Implementation Architecture

Results split into two namespaces: `IsCMField` handles the standard CM case (K totally complex, quadratic over K⁺), while `CMExtension` treats the general case where K/F is a CM-extension with arbitrary totally real field F.
