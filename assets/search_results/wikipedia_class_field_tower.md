## Golod–Shafarevich Theorem (Wikipedia)

### Overview

The **Golod–Shafarevich theorem** is a result in non-commutative homological algebra proved in 1964 by Evgeny Golod and Igor Shafarevich. It "solves the class field tower problem, by showing that class field towers can be infinite."

### The Fundamental Inequality

For a graded algebra B = A/J where A is a free algebra over a field with d generators, and J is an ideal generated by homogeneous elements rᵢ of degree i (with rᵢ of them at each degree), the dimensions bⱼ = dim Bⱼ satisfy:

> b_j ≥ nb_(j-1) − Σ(i=2 to j) b_(j-i) · rᵢ

**Key consequence:** B is infinite-dimensional when rᵢ ≤ d²/4 for all i.

Equivalently: if the generating function of relations R(t) = Σ rᵢ tⁱ satisfies R(t) ≤ (1 - dt)²/4 = (dt - 1)²/4 ... (i.e., the number of relations is small relative to the number of generators), then B is infinite-dimensional.

### Applications

#### Combinatorial Group Theory

For finite p-groups G, the theorem implies:
- The number of relators r in a minimal presentation satisfies r > d²/4, where d is the minimum number of generators
- This gives: "there is an infinite group G generated by three elements in which each element has order a power of p" — providing a counterexample to the generalized Burnside conjecture

#### Class Field Tower Problem

**The Problem (Furtwängler/Hasse, 1926):** Starting from a number field K, form the Hilbert class field H(K), then H(H(K)), etc. Does this tower always terminate?

**Resolution:** The Golod-Shafarevich theorem shows the answer is NO — towers can be infinite.

**Specific result:** An imaginary quadratic field K whose discriminant has at least 6 prime factors has an infinite maximal unramified 2-extension, i.e., the 2-class field tower K ⊂ K₁ ⊂ K₂ ⊂ ... is infinite.

**Why 6 prime factors?** For an imaginary quadratic field K = Q(√-d), the 2-rank of the class group satisfies rank₂ Cl(K) ≥ ω(d) - 1 where ω(d) is the number of distinct prime factors of d. With 6+ prime factors, rank₂ Cl(K) ≥ 5, giving enough generators for Golod-Shafarevich to apply.

More precisely: For the pro-2 completion of Gal(K^ur/K) (where K^ur is the maximal unramified 2-extension), we have:
- d = rank₂ Cl(K) ≥ 5 (generators)
- r ≤ d(d-1)/2 + 1 (from the structure of the pro-p group) or similar bounds

The Golod-Shafarevich criterion d² > 4r is satisfied.

### Quantitative Bounds

For a number field K with r₂ complex places, Odlyzko bounds give:
- rdiscr(K) ≥ 60^(1 - r₁/n) · (2π e^γ)^(r₂/n) · (1 + o(1)) as n → ∞ (Zimmert bound)

Fields with small root discriminant (near these bounds) are candidates for towers with bounded root discriminant.

The key inequality for infinite towers: if d (number of generators of the p-class group) and r (number of relations in the pro-p group presentation) satisfy r < d²/4, then the tower is infinite.

### Historical Context

- 1926: Hasse documents Furtwängler's question about class field tower termination
- 1964: Golod and Shafarevich prove their theorem, resolving the problem
- 1985: Schoof finds explicit examples of imaginary quadratic fields with infinite 2-class tower
- 1994: Hajir-Maire begin studying asymptotically good towers
- 2000: Hajir-Maire, asymptotically good towers of global fields (ECM 2000)
- 2019: Hajir-Maire-Ramakrishna, "Cutting towers of number fields" (arXiv:1901.04354)

### Key Formula: Root Discriminant Bounds for Infinite Towers

For a totally complex CM field K of degree 2f:
- rdiscr(K) = |disc(K)|^(1/(2f))
- Odlyzko lower bound: rdiscr(K) ≥ (2πe^γ)^(1+o(1)) ≈ 22.3... as f → ∞
- Martinet bound for totally complex fields: rdiscr(K) ≥ (e^(2πγ))^(1+o(1)) ≈ ... (more precise)
- Explicit achievable bound: Hajir-Maire achieve rdiscr ≤ 82.2 for totally complex infinite towers

For the unit distance application, one needs CM fields with:
1. rdiscr bounded (ensures Minkowski bound M(K) ≤ C · [K:Q]^C for some constant C)
2. h(K)/[K:Q]^f growing slowly (ensures enough norm-1 elements per unit of degree)
3. Specific rational primes p splitting completely in all levels
