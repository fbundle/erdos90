# Golod–Shafarevich Theorem

## Introduction

In mathematics, the **Golod–Shafarevich theorem** was proved in 1964 by Evgeny Golod and Igor Shafarevich. It is a result in non-commutative homological algebra which solves the class field tower problem, by showing that "class field towers can be infinite."

## The Inequality

Let A = K⟨x₁, ..., xₙ⟩ be the free algebra over a field K in n = d + 1 non-commuting variables xᵢ.

Let J be the 2-sided ideal of A generated by homogeneous elements fⱼ of A of degree dⱼ with:

2 ≤ d₁ ≤ d₂ ≤ ...

where dⱼ tends to infinity. Let rᵢ be the number of dⱼ equal to i.

Let B = A/J, a graded algebra. Let bⱼ = dim Bⱼ.

The **fundamental inequality** of Golod and Shafarevich states:

bⱼ ≥ nbⱼ₋₁ − Σᵢ₌₂ʲ bⱼ₋ᵢrᵢ

As a consequence: B is infinite-dimensional if rᵢ ≤ d²/4 for all i.

## Applications

### Combinatorial Group Theory

If G is a nontrivial finite p-group, then r > d²/4, where d = dim H¹(G, Z/pZ) and r = dim H²(G, Z/pZ).

For each prime p, there exists "an infinite group G generated by three elements in which each element has order a power of p." This group provides a counterexample to the generalised Burnside conjecture.

### Class Field Theory

The class field tower problem asks whether the tower created by iterating the Hilbert class field construction is always finite. The Golod–Shafarevich theorem demonstrates that "such towers may be infinite."

Specifically: "Let K be an imaginary quadratic field whose discriminant has at least 6 prime factors. Then the maximal unramified 2-extension of K has infinite degree."

More generally, a number field with sufficiently many prime factors in the discriminant has an infinite class field tower.
