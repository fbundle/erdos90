# References and External Resources

## 1. Class Number Bounds

- **Washington, "Introduction to Cyclotomic Fields"**
  - Essential reference for class numbers of cyclotomic fields.
  - Chapter 4: Class numbers of cyclotomic fields.
  - Chapter 11: $L$-functions and class number formulas.

- **Louboutin, "Explicit upper bounds for residues of Dedekind zeta functions and class numbers of CM-fields" (2000)**
  - Provides sharp explicit bounds for $h_K$.
  - Found in `assets/louboutin_2000_class_number.pdf`.

- **Debarre, "Sur les facteurs de Schur des groupes de Galois" (1987)**
  - Provides the bound $h_p^- \le 2p (p/24)^{(p-1)/4}$.

## 2. Golod-Shafarevich and Class Field Towers

- **Hajir, Maire, and Ramakrishna, "Unramified towers and Golod-Shafarevich groups"**
  - Standard reference for the construction of infinite unramified towers.
  - Found in `assets/hajir_maire_ramakrishna_2021.pdf`.

- **Neukirch, "Algebraic Number Theory"**
  - General reference for Minkowski bounds, discriminants, and class groups.
  - Chapter I, §6 (Minkowski Theory).
  - Chapter I, §7 (Class Group).
