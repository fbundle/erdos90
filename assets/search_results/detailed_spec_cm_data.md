# Detailed Specification: `exists_cm_class_group_data` (Sawin Construction)

This document provides the exhaustive mathematical details required to formalize the CM class-group construction from Sawin (arXiv:2605.20579, Prop 2.2).

## 1. Input Data
*   **CM Field $K$**: Degree $2f$, totally imaginary quadratic extension of totally real $F$.
*   **Split Primes**: $m$ prime ideal pairs $\{\mathfrak{P}_s, c\mathfrak{P}_s\}$ in $\mathcal{O}_K$ lying above split primes $q \in S_{\mathbb{Q}}$.
    *   $m = \sum_{p \in S_{\mathbb{Q}}} \text{count primes above } p$.
*   **Lattice $\Lambda$**: $\Phi(D_0^{-1} \mathcal{O}_K)$.

## 2. Construction of $E$ and $\phi$
*   **Type $E$**: $\{0, 1\}^m$ (binary sign vectors).
*   **Type $G$**: `ClassGroup (𝓞 K)`.
*   **Map $\phi$**: $\phi(\epsilon) = [\prod_{s=1}^m \mathfrak{P}_s^{\epsilon_s} \cdot (c\mathfrak{P}_s)^{1-\epsilon_s}]$.
    *   This maps each sign vector to the ideal class of the corresponding product of prime ideals.
*   **Norm Condition**: For any $\epsilon$, $N_{K/F}(\text{ideal}(\epsilon)) = \prod \mathfrak{p}_s$ (the prime ideals in $F$ below the pairs). This is constant for all $\epsilon$.

## 3. The Pigeonhole Argument
*   By the pigeonhole principle, there exists a fiber $F \subseteq E$ with $|F| \geq |E| / |G|$.
*   We need $|E| / |G| \geq \exp(\gamma f) + 1$.
*   **Louboutin Bound**:
    $$h^-(K) \leq 8 \operatorname{rd}_{K/F}^2 \left( \sqrt{\operatorname{rd}_{K/F}} \log(\operatorname{rd}_{K/F}) \frac{e}{4\pi} \right)^f$$
    *   Since $\operatorname{rd}_{K/F}$ is fixed (from the GS tower), $h^-(K)$ grows as $C^f$.
    *   $|E| = 2^m = 2^{tf}$ also grows as $(2^t)^f$.
    *   By choosing $t$ large enough (based on the root discriminant), we ensure $2^t > C$, so the ratio grows exponentially.

## 4. Unit Construction (`mk_unit`)
*   Given $\epsilon_1 \neq \epsilon_2$ such that $\phi(\epsilon_1) = \phi(\epsilon_2)$.
*   The ideal $\mathfrak{A}_{\epsilon_1} \mathfrak{A}_{\epsilon_2}^{-1}$ is principal, generated by some $\alpha \in K^\times$.
*   **Norm-1 Element**: $u = \alpha / c(\alpha)$.
    *   $|\sigma(u)| = 1$ for all complex embeddings $\sigma$ (proved in `NumberFieldDeep.lean`).
    *   $u \in D_0^{-1} \mathcal{O}_K$ because the valuations at the split primes are controlled.
*   **Lattice Vector**: The Minkowski embedding $\Phi(u)$ gives a vector in $\Lambda$ where every coordinate has modulus 1.

## 5. Injectivity Proof (`mk_unit_inj`)
*   Suppose $u_1 = u_2$ for two different elements in the same fiber (with fixed $\epsilon_1$).
*   $\alpha_2 / c(\alpha_2) = \alpha_3 / c(\alpha_3) \implies \alpha_2 / \alpha_3 = c(\alpha_2 / \alpha_3)$.
*   This implies $\alpha_2 / \alpha_3 \in K^+ = F$ (totally real subfield).
*   The ideal $(\alpha_2 / \alpha_3) = \mathfrak{A}_{\epsilon_2} \mathfrak{A}_{\epsilon_3}^{-1}$ is an ideal in $F$.
*   In a CM extension, an ideal in $F$ must have even valuation at all split primes (since they split as $\mathfrak{P} \cdot c\mathfrak{P}$).
*   But $\mathfrak{A}_{\epsilon_s}$ was constructed by picking **one** prime from each pair.
*   $v_{\mathfrak{P}_s}(\mathfrak{A}_{\epsilon_2} \mathfrak{A}_{\epsilon_3}^{-1}) = \epsilon_{2,s} - \epsilon_{3,s} \in \{0, 1, -1\}$.
*   For this to be even, it must be 0, so $\epsilon_{2,s} = \epsilon_{3,s}$ for all $s$.
*   Thus $\epsilon_2 = \epsilon_3$.
