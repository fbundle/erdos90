# Mathlib.NumberTheory.Cyclotomic.Basic - Full Documentation

## Overview

This documentation covers cyclotomic extensions in Mathlib4, a formal mathematics library. The module defines structures for representing field extensions generated by roots of unity.

## Main Definitions

**IsCyclotomicExtension**: A class expressing that ring `B` extends `A` by adjoining `n`-th primitive roots of unity for all nonzero `n` in a set `S`. It requires:
- Existence of primitive roots: "For all nonzero `n ∈ S`, there exists a primitive `n`-th root of unity in `B`"
- Generation property: "`n`-th roots of unity, for `n ∈ S` nonzero, generate `B` as an `A`-algebra"

**CyclotomicField**: Defined as "the splitting field of `cyclotomic n K`" for a field `K` and natural number `n`. When `n` is nonzero in `K`, it automatically has a cyclotomic extension instance.

**CyclotomicRing**: For an integral domain `A` with fraction field `K`, this is "the `A`-subalgebra of `CyclotomicField n K` generated by the roots of `X ^ n - 1`".

## Core Theorems

**Transitivity** (`trans`): If `B` is a cyclotomic extension of `A` and `C` is a cyclotomic extension of `B` with injective algebra map, then `C` is a cyclotomic extension of `A` with combined index sets.

**Finiteness** (`finite`): "If `S` is finite and `IsCyclotomicExtension S A B`, then `B` is a finite `A`-algebra."

**Number Field Extension** (`numberField`): A finite cyclotomic extension of a number field is itself a number field.

**Galois Properties**: Cyclotomic extensions are separable, Galois, and abelian over their base fields.

**Splitting Fields**: Extensions satisfying `IsCyclotomicExtension {n}` are splitting fields for both `X^n - 1` and the `n`-th cyclotomic polynomial.

## Key Lean API

- `IsCyclotomicExtension.Rat.isCMField` — cyclotomic extensions ℚ(ζ_n) with n > 2 are CM (in `NumberField/Cyclotomic/Basic.lean`)
- `discr_prime_pow` — explicit discriminant formula for ℚ(ζ_{p^k}) (in `Cyclotomic/Discriminant.lean`)

## Implementation Notes

The definition generalizes to arbitrary characteristic and infinite extensions. Most results use the `IsCyclotomicExtension` namespace. Some results (transitivity, finiteness, Galois properties) are technically lemmas but can be made local instances via the `Cyclotomic` locale.
